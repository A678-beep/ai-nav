DeepSeek API 价格与缓存命中实测

对话AI·更新于 2026-11-15·DeepSeek API 价格, DeepSeek 缓存命中, DeepSeek 计费, DeepSeek 缓存命中怎么算, DeepSeek 空闲时段价格

上个月把客服摘要从另一家模型迁到 DeepSeek，月底账单 46 元，比我按字符数拍脑袋估的 120 元低了一半多。不是内部折扣，而是我先花半小时把 2026 年这版 DeepSeek API 价格拆成三行，又把调用挪进空闲时段。下面是对账方法，也包括缓存命中率归零的坑。

三行价格表，先看输出

现在的模型只有 deepseek-flash 和 deepseek-v4-pro 两个，价格按百万 tokens 计。以 flash 为例：输入缓存命中 0.02 元，未命中 1 元，输出 4 元；高峰时段全部翻倍，分别是 0.04 元、2 元、8 元。v4-pro 更贵，空闲时段是 0.15 元、4.5 元、13.5 元。记住两个倍数：输出是未命中输入的 4 倍，缓存命中只有未命中的五十分之一。所以省钱第一顺位是提高命中率，第二顺位才是压输出。pro 的未命中输入是 flash 的 4.5 倍，翻译、摘要这类活直接用 pro 就是多花钱。DeepSeek 空闲时段价格只有高峰的一半：高峰是北京时间周一至周五的 9:00-12:00 和 14:00-18:00，法定节假日不算，其余时间包括周末全天都半价。我有个每天 200 次的日报机器人，每次输入 8000 tokens、命中率八成、输出 800 tokens，输入命中 1.28M×0.04=0.05 元、未命中 0.32M×2=0.64 元、输出 0.16M×8=1.28 元，一天约 1.97 元；全挪到空闲时段约 1 元，一个月差 30 元。

让缓存命中的三个写法

缓存按前缀匹配，请求开头的字节完全一样才有机会命中。第一，把固定的系统提示、输出格式、工具说明全部放在最前面，时间戳、用户名、随机 ID 挪到后面。第二，多轮对话别每次重拼 system，历史消息原样带上，中间别插新内容。第三，用接口返回的 usage.prompt_cache_hit_tokens 和 prompt_cache_miss_tokens 对账，别自己猜命中率。我第一版把日期写在最前面，命中率一直是 0，账单是现在的 50 倍，改完前缀当周就降下来了。缓存没有官方承诺的固定有效期，隔天同一前缀不一定命中，别把它写进对外报价。

账单里的两个坑

坑一是 token 之外的费用。联网搜索和网页抓取是 5 元每千次，文件解析与 OCR 是 1.5 元每千页，TTS 3 元每万字符、ASR 0.78 元每小时，这些都不在 DeepSeek API 价格的 token 项里。我第一版每轮都开联网，单次两三分，一千次五块，比模型费还贵。坑二是模型名，旧代码里的 deepseek-chat 已进弃用名单，要换成 deepseek-flash，哪天接口切走就得报错。另外思考模式默认开启，推理 token 计入输出，做摘要时关掉能省三到五成；余额和并发限制也看一眼，flash 是 2500、pro 是 500，超了报 429。同事问我 DeepSeek 缓存命中怎么算，我让他先把 usage 里两组数抄出来，再对照 DeepSeek API 价格表。

总结

现在我估算 DeepSeek API 价格只用一条公式：输入命中量×0.02 加输入未命中量×1 加输出量×4，flash 按 DeepSeek 空闲时段价格直接套，高峰翻倍。对账时打开 usage 字段，把命中、未命中、输出分开看，再核对搜索和解析的附加费用。DeepSeek 缓存命中怎么算，就是这两组 token 分开乘单价，别用一个平均价糊过去。先把前缀缓存做对，再排空闲时段，最后才考虑换模型；命中率归零那次让我交了 50 倍学费。
