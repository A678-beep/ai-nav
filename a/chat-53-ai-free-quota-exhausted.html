免费额度 用尽之后：先别急着掏钱

周一早九点，客户六篇笔记等着改，ChatGPT 免费版提示 5 小时窗口到顶，Claude 也说当天条数用完了。这是我这个月第三次碰上免费额度 用尽，前两次一急就绑卡，月底一看三笔订阅只常用了一笔。后来我把顺序固定成三步：先查还有哪些免费入口，再拆任务，最后才决定给谁掏钱。

免费额度用完了怎么办，先查三处

第一处是重置周期。ChatGPT 免费版按 5 小时滚动，超了旗舰降成小模型，小模型不限量；Claude 免费版每天约 40 条，长文常先撞条数；Gemini 网页版旗舰每天几次，但 AI Studio 的免费 API 每天 250 次，和网页版分开算；豆包、Kimi 网页版不限次，长文档和联网搜索按次限流。网页版和 API 是两个钱包，这是最容易忽略的。第二处看任务能不能拆，三千字长文切四章、每章八百字单独跑，格式整理换小模型。第三处才是换工具，换之前先算提示词和输出格式要不要重搭，我迁过一次，模板重写两小时，比等额度重置还久。

钱只花在断供就停的那一环

工具分三类：每天开工就要用的、一周用两三次的、应急才打开的，钱只花第一类。档位也简单：主力对话个人版 20 美元约 145 元一个月；按量 API 作补充，DeepSeek flash 输入命中 0.02 元、未命中 1 元、输出 4 元每百万 token，正常写稿一个月二三十元；垂直工具单买 10 到 20 美元。判断标准写死两条：一个月断供三次以上，或者每次断供损失超过一小时，才把免费档升级成订阅。145 元要换回三小时以上的时间才不亏。免费额度 用尽那天再算账，比月初凭感觉买稳；AI 工具 额度 怎么续费，先想清楚续的是入口还是习惯。

案例：两个人的工作室

朋友的工作室两个人，每月 18 篇笔记加 6 篇长文。原来配三个订阅、每月 480 元，月底发现两个工具一周没打开。改成写长文用 Claude Pro，批量摘要走 DeepSeek API，长文阅读用 Kimi 免费档，配图用即梦免费额度，月成本 145 元加 28 元 API。代价是每天多花十分钟切工具，两人商量后接受，一个月省下 300 多元。现在每月固定留 50 元应急额度，稿子赶的时候直接走按量 API，不再临时绑卡，这笔钱三个月只花掉 62 元。避坑两条：免费试用绑卡会自动转付费，开卡当天就去关自动续费；别用多开小号绕额度，账号被风控后历史对话一起丢。

总结

免费额度 用尽不是掏钱的信号，是重新排任务的信号。先查网页版和 API 两个钱包、再算重置时间，把任务降档拆开，最后按断供次数决定买哪个。免费额度用完了怎么办，我固定按三步走；AI 工具 额度 怎么续费，答案往往是换入口而不是开新卡。
