Grok 3 实时搜索实测复盘

对话AI·更新于 2026-11-15·Grok 3, 实时搜索, DeepSearch, Grok 3 追科技新闻, DeepSearch 使用方法

做科技号最怕两件事：错过了当天的消息，把旧闻当新闻发。上个月我开始用 Grok 3 做实时搜索，盯二十四小时内的科技动态，每天两轮，一轮十分钟，比我原来刷十几个信息源快。它的优势是直接接社交媒体，劣势也在同一个地方：快，但脏。下面把我摸出来的 DeepSearch 使用方法和核验习惯写清楚。

两段式提问

第一步点开搜索框下面的增强搜索按钮，普通对话模式不联网，问最新消息只会给训练数据里的旧结论。第二步先发散：列出过去二十四小时关于某家公司的十条消息，按时间排序，每条给出来源。第三步再收敛：只保留有官方公告或主流媒体确认的三条，标注发布时间，说明消息来源是谁。第四步打开回答下方的来源面板，逐条点开核，链接打不开的直接标存疑。我测过一轮，十条里能站住的三到四条，比例不算低，但必须先发散再收敛，直接问重点会漏掉关键信息。这套 DeepSearch 使用方法简单，难在每次都忍住不跳过第二步。

怎么防它把旧闻当新闻

上周一条融资消息被它排在今天，点开来源是三个月前的帖子，转载号重新发了一遍。做 Grok 3 追科技新闻，我的做法是：提问时明确要求每条消息标注原始发布时间，和来源页面上的日期对不上就划掉；涉及数字的，去官网或公告截图对一遍，它引用的二手转述经常把金额单位写错。中文场景它也吃亏，国内厂商的动态英文信源更新慢，建议交叉用国内媒体再搜一遍。整个增强搜索平均一分钟左右出结果，追问三轮就接近三分钟，别在它身上等太久。真正值钱的是来源面板，不是那段总结。

四个坑

一是社交平台上的搬运号和热帖优先级很高，热度不等于真实，越耸动的标题越要核。二是它给的引用链接会失效，尤其是帖子被删之后，回答还在，来源已经打不开，重要事实必须落到官网。三是日期容易混，它常把旧帖算进当天，务必让它标原始发布时间。四是增强搜索有次数限制，免费额度用完之后只能等，重要提问一次说清，别拿它闲聊。另外实时搜索对中文长尾事件覆盖一般，冷门行业新闻还是得看垂直媒体。

总结

Grok 3 实时搜索适合当第一层雷达：先用增强搜索铺开二十四小时的信息，再用官网和公告收敛到三到四条。它负责快，人负责准。养成核来源和核日期的习惯，能省掉大部分翻车。Grok 3 追科技新闻真正省时间的地方，是你知道该去哪里二次确认。
