ComfyUI 节点 报错：红框、版本与显存

图像生成·更新于 2026-11-15·ComfyUI 节点 报错, 缺失节点, 显存不足, 自定义节点, ComfyUI 缺少 模型 红框, ComfyUI 报错 日志 在哪看

上周帮同事跑一套 Flux 工作流，JSON 导进去 12 个节点红了 3 个，点 Queue 只弹一句 Prompt outputs failed validation。ComfyUI 节点 报错 最容易被误判成工作流坏了，其实红框的形状、模型下拉框里有没有文件、终端最后三行，已经把原因交代得差不多。

红框先分缺节点还是缺模型

导入后先看红框。节点整块标红、弹窗写着 When loading the graph, the following node types were not found，那是缺自定义节点：关掉弹窗，打开 Manager 点 Install Missing Custom Nodes，装完必须完全重启，再 Ctrl+F5 硬刷新一次界面。还红就去终端搜 IMPORT FAILED，后面跟的目录名就是没加载成功的包，多半是依赖没装或文件夹名字被改过。Manager 里搜不到时，把弹窗里的类名整段粘进搜索框，再不行去作者仓库核对目录名。另一种是模型没加载，点 Queue 报 Prompt outputs failed validation: CheckpointLoaderSimple: Value not in list: ckpt_name: 'flux1-dev.safetensors' not in []，中括号空着说明一个文件都没读到。先去 models/checkpoints 核对文件名的大小写和后缀，改完点刷新。我那次是 flux1-dev 放在 models/unet，工作流却用 CheckpointLoaderSimple 读，列表当然是空的，换成 UNETLoader 加 DualCLIPLoader 就通了。这类 ComfyUI 缺少 模型 红框，八成不是文件丢了，是目录或加载器选错。

版本不匹配和显存是两类硬报错

广告位（文章中部）AdSense / 广告联盟代码插入点 · 建议 728×90 / 移动端 320×100

更新前端后最容易撞版本。旧自定义节点报 ImportError: cannot import name，或者连线时报 Return type mismatch between linked nodes: model, MODEL != CLIP，都是输入输出类型变了。别急着重装环境，先到 custom_nodes 目录看 git log，回退到上一个 tag；或者用 Manager 的 Snapshot 恢复到能跑那天。顺序也讲究：先备份 custom_nodes 和 requirements，再升主程序，跑一遍最简文生图，最后才升自定义节点。显存报错通常落在 KSampler 和 VAE Decode 上，终端刷 CUDA out of memory. Tried to allocate 2.00 GiB。先看是不是上一次的模型没释放，菜单里点 Unload Models 和 Free model and node cache；再把 batch size 降到 1、1024 改 768；12G 卡先加 --lowvram，6G 以下再上 --novram。ComfyUI 报错 日志 在哪看 后面会说，显存这类先看终端比翻界面快。

日志定位：前端看 Console，后端看终端

前端验证失败的细节在浏览器里。F12 打开 Console 再点一次 Queue，Prompt outputs failed validation 后面会跟具体字段，最常见的是 Required input is missing: clip。我有一次界面只显示失败，Console 里写着 clip 缺失，回画布发现 CLIPTextEncode 上游的 CLIPSetLastLayer 没连线，补一根线 3 分钟出图，之前已经白试了 25 分钟。后端错误看启动终端：缺节点的 traceback、模型加载失败、显存栈都在那。启动时加 --verbose DEBUG 能多打不少行，用 bat 启动的把输出重定向到 log，事后回翻比凭记忆强。日志里先搜 Error，再搜节点的 class_type，两行通常挨着。还有种报错长得像随机数：mat1 and mat2 shapes cannot be multiplied (128x768 and 3072x768)，这是 SDXL 工作流挂了 SD1.5 的 LoRA，换 LoRA 就好。所以有人问 ComfyUI 报错 日志 在哪看，我的答案永远是两个地方，浏览器 Console 和启动终端。ComfyUI 节点 报错 排查到最后拼的是能不能在一行日志里认出类型，认出来就不用瞎试参数。

总结

固定顺序是：看红框类型、看模型下拉、对版本、看显存，最后才翻日志，五步一般 5 分钟出结论。ComfyUI 节点 报错 里真正难修的很少，多数是目录、版本、显存三件事放错位置；ComfyUI 缺少 模型 红框 也多半是路径和加载器的问题。
