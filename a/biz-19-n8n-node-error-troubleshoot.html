n8n 节点 报错 排查：5 类常见错误与重试

商业效率·更新于 2026-11-15·n8n 节点 报错 排查, n8n 报错 日志, n8n 表达式, 重试策略, n8n 报错 日志 查看, n8n 表达式 报错

周三早上 8 点，日报那条工作流没出数。我打开左侧的 Executions，列表里一条红色 Failed，点进去红的是 HTTP Request 节点，返回 429。整条链路 18 个节点，每天抓 42 个源，前一周其实已经失败 17 次，只是没人翻执行记录。n8n 节点 报错 排查 我不靠猜，固定看三处：执行记录里哪个节点红、该节点的 INPUT 和 OUTPUT、错误码对应哪一种改法。

一、五类错误先对号入座

高频的就五类。第一类 401 和 403，凭据过期或权限不够，HTTP Request 返回体里 message 写得很直白，401 换 token，403 去授权页补 scope。第二类 429，请求太密被限流，先看响应头 Retry-After 写了几秒，再决定等多久。第三类 ECONNREFUSED、ETIMEDOUT、EAI_AGAIN，分别是对方服务没起、端口写错、域名解析失败，在本机用 curl 验一遍再回来看节点。第四类最坑：接口返回的其实是登录页 HTML，Response Format 却选了 JSON，报错 Unexpected token < in JSON at position 0，改成 Text，或者先加个 IF 判断标题。第五类 5xx 是上游自己的问题，重试基本没用，跳过并写一行到异常表；返回 400 先怀疑请求体字段和类型对不上，报错原文里的 field 名拿去搜节点配置，比看堆栈快。

二、表达式和日志：把错误锁死在一个节点

不少报错不在接口，在表达式。字段名带空格得用方括号，{{ $json["access token"] }} 比点号稳；取任意上游节点用 {{ $('HTTP Request').item.json.data }}，旧写法 $node["HTTP Request"].json.data 也能跑，但字段一深常报 Cannot read properties of undefined (reading 'data')，九成是那条分支没数据，不是语法错。Set 节点里另一类坑：字段类型选了字符串，表达式返回数字，看着能跑，下游一比较就错分支。

n8n 报错 日志 查看 分界面和容器两层：界面在 Executions 里筛 Failed，点红节点切 INPUT 和 OUTPUT；容器用 docker logs n8n --tail 200，自建版把 N8N_LOG_LEVEL 设成 debug 再复现一次。执行记录按天清理，把 EXECUTIONS_DATA_MAX_AGE 调到 720 小时，事后翻旧账才翻得到。n8n 表达式 报错 还有一类是类型：文本框只收字符串，表达式却返回对象，看着像报错，其实接一个 JSON.stringify 就过。n8n 表达式 报错 里最难认的是空数组，$json.data[0].id 取不到就整条断，加个 IF 兜住。

三、重试策略和一条真实案例

把 On Error 从 Stop Workflow 改成 Continue (using error output)，读操作再开 Retry On Fail：Max Tries 填 5，Wait Between Tries 填 3000 毫秒。HTTP Request 的 Batching 里 Batch Size 填 5、Batch Interval 填 1000，42 个源不再一把怼过去。写操作别这么配，POST 建单、发消息一重试就重复提交，只能走 error output 挂补偿分支。重试也不是越多越好：Max Tries 超过 5 意义不大，Wait Between Tries 低于 1000 毫秒等于没退避。

n8n 节点 报错 排查 落到这条 429 上：18 个节点、每天跑 1 次、第三个 HTTP Request 失败，一周 17 次。改完重试和分批，一周降到 1 次，剩下那次是对方封 IP，换成 2 个 key 轮换后归零。再在 Settings 里接一条 Error Workflow，用 Error Trigger 把 {{ $json.execution.error.message }} 推到群里，5 分钟内能知道，不用等业务方来问为什么没数据。

总结

n8n 节点 报错 排查 的顺序固定下来就三步：Executions 筛失败、点开红节点看输入输出、对错误码改 On Error 和重试。时间八成花在没看入参就动手改。重试只给读操作，写操作走补偿；n8n 报错 日志 查看 时把 EXECUTIONS_DATA_MAX_AGE 调大；告警接上，别等数据断了一天再回头查。
