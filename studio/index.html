❓ 使用帮助

这个页面帮商家把「一句话 + 几张素材」变成能直接发的竖屏短视频。全程不需要剪辑基础。

3 步就能出片

  1. 选模板：门店开业 / 餐饮菜品 / 汽修洗车 / 家政 / 美业 / 教培，6 选 1。
  2. 传素材：传 1~3 张门店照或视频。没有就跳过，系统自动配可商用素材。
  3. 写一句话：把优惠、地址、时间说清楚，点「🎬 生成商家视频」。

生成要多久？可以关页面吗？

通常 40~130 秒。生成时别关页面、别重复点；按钮会自己变成「正在出片…」。

改稿会重新收费/排队吗？

点「字幕放大」「换 BGM」等会重新出片，40~95 秒。每改一次存一版，点版本记录可回退。

为什么提示「极限词」？

广告法不允许「最好 / 第一 / 顶级」这类绝对化用语。系统会先提醒，建议换成价格、份量、服务等具体卖点。

会自动保存吗？关掉页面会丢吗？

会。需求、模板、时长、素材、分镜和作品编号会自动存在本机浏览器，顶部显示「已自动保存 时间」。刷新或关掉再打开，会问你要不要继续上次草稿；生成中关掉也能回来接着查结果。

怎么把视频、音轨和文案存到一个文件夹？

成片后点「📁 选择保存文件夹并下载」，Chrome/Edge 可以一次写入视频、配音、配乐、口播文案、营销文案、镜头脚本和授权说明；其他浏览器会自动改成普通下载。草稿也能导出 .json，换电脑再导入。

手机上能用吗？

可以，页面按手机竖屏做过适配。点右上「👴 大字模式」还能放大字体和按钮。

生成失败怎么办？

先点「🔁 再试一次」；连续失败就换更短的说法，或减少素材。还不行请用国内站 xinglaiai.com。
