安装步骤（3 步）

  1. 先登录星籁 AI 账号（与网页工作台同一个账号），再点上面的「下载安装包」，得到 星籁剪辑-0.2.11-setup.exe（约 101.6 MB）。
  2. 双击安装；如果 SmartScreen 拦截，点「更多信息 → 仍要运行」。装完桌面/开始菜单会有「星籁剪辑」。
  3. 打开后用星籁 AI 账号登录（与网页工作台同一个账号），即可本地剪辑；不登录也能先用本地模式。

安装包只包含 Windows x64 版本；macOS / Linux 版本还在路线图中。

系统要求

  • Windows 10/11 64 位（x64），建议 16GB 内存、支持 DX12 的显卡（AMD / NVIDIA / Intel 均可）。
  • 约 2GB 磁盘空间用于安装；4K 工程与素材另计。无独显时可软件渲染，但 4K 预览会明显变慢。
  • 首次运行自动字幕/抠像等功能时，会按需下载模型（不随安装包分发）。
