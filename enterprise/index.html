ROI 算法（可给 CFO 看）

            
节省工时 = 任务量 × 单次耗时 × 自动化率
节省成本 = 节省工时 × 人力时薪
LLM 成本 = Σ(prompt tokens×¥2/百万 + completion tokens×¥8/百万)
净节省   = 节省成本 − LLM 成本 − 平台费用
ROI      = 净节省 / (LLM 成本 + 平台费用)

            
ROI 为基于规则的估算，用于试点期决策参考，不构成财务承诺。缓存命中与降级回答不产生 LLM 成本。

私

          
私有化部署

          
一键部署包交付到企业自有服务器 / 专有云；数据不出企业边界；支持客户自有模型 Key（BYOK）与内网模型。分部门权限、全量审计日志、可删除数据。

        

        

          
经

          
经济模式（成本可控）

          
单次输出 ≤1200 tokens、相似问题缓存、每日总量上限；无模型 / 余额不足时自动降级为“知识库检索结果 + 模板回答”，保障演示与生产可用性。

        

        

          
审

          
合规与审计

          
AI 生成标识、不训练客户数据、不承诺准确率 100%；合同 / 财务 / 人事等敏感事项强制人工复核；租户隔离、成员角色与操作审计。

        

      


      

        
ROI 算法说明（可给 CFO 看）

        

          
节省工时 = 任务量 × 单次耗时 × 自动化率
节省成本 = 节省工时 × 人力时薪
LLM 成本 = Σ(prompt tokens×¥2/百万 + completion tokens×¥8/百万)
净节省   = 节省成本 − LLM 成本 − 平台费用
ROI      = 净节省 / (LLM 成本 + 平台费用)

          
    
            
  • 默认口径：单次对话节省 5 分钟、自动化率 100%、人力时薪 ¥60、平台月费按 POC 假设；管理员可在 ROI 看板按企业实际调整。
    • 
            
  • 记账真实：每次对话记录任务、tokens、耗时与成本；缓存命中与降级回答不产生 LLM 成本。
    • 
            
  • 不承诺：ROI 是规则估算，用于试点期对比与决策，不构成财务承诺；正式验收以双方确认的基线与口径为准。

2–4 周 POC 试点流程

        

          
W1
调研与选场景
部门 / 流程 / 知识 / 系统盘点，选 1 个高价值场景（建议客服或销售）。

          
W2
知识库 + 1 个智能体上线
导入企业文档，配置岗位提示词与 SOP，小范围试用。

          
W3
调优 + 接 1 个系统
按真实问答调优，接 1 个业务系统（CRM / 工单 / 企微），建立 ROI 基线。

          
W4
验收报告 + 推广计划
ROI 数据、使用报告、扩编与私有化落地计划。
