合规与风险提示

强监管行业先看合规，再谈效果；以下为方案内置的合规边界。

  • 食安建议仅辅助，不替代门店食品安全员与监管检查；涉及处罚口径须以监管部门为准
  • 广告与菜品宣传禁用“最/第一/治疗功效”等表述，AI 物料需人工复核
  • 外卖/点评数据抓取须遵守平台协议，优先用官方导出或 API
