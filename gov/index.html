Security First · 安全与保密

政府最担心的不是模型能力，而是数据泄密——所以安全与保密放在第一位

平台部署在客户内网 / 政务云专属区，知识库、模型、日志全部在边界内流转。 我们不接触客户数据、不留存原始对话、不允许任何跨租户访问。

🔒不接触涉密数据

平台只处理客户授权范围内的业务数据。涉密数据不入库、不出域，部署与运维全程在客户边界内完成。

✓ 涉密数据物理隔离 · 运维远程不可见
🗂️不留存客户数据

支持全量私有化部署；默认不留存原始对话，日志按客户策略留存与到期清理（默认 180 天可配置）。

✓ 数据留存策略客户可控 · 支持一键清理
🧱不跨租户访问

租户级数据隔离 + RBAC/ABAC 双重校验；任何跨租户、跨部门的越权访问都会被拒绝并计入审计。

✓ 隔离 + 拒绝 + 留痕 三件套

Architecture · 技术架构

知识库 → Agent 编排 → 模型网关 → 渠道 → 审计

全链路可私有化：检索与生成都在客户边界内完成；模型可替换为国产模型或客户自建模型；每一步都留审计。

渠道层：统一入口 + 角色授权 Agent 编排：意图路由与流程串联 模型网关：国产模型统一接入 知识库：切片 + 向量 + 权限标签 审计与安全：贯穿所有层
🧩
