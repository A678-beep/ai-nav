涉密隔离与数据边界说明

曦沃·中枢 · 政务垂类 v1.0 · 本页为可交付的合规说明（1 页）
私有化部署数据不出内网涉密不入模型审计留存 180 天

一、数据分级与处置

级别能否进入模型典型内容
公开可以对外发布的政策、办事指南、公告、常见问答
内部脱敏后可进入含个人信息、联系方式、内部地址、未公开数据——须先去标识
涉密禁止进入标注"绝密 / 机密 / 秘密"或涉密载体内容——一律人工流程处理

二、五条硬控制（服务内自动执行）

  1. 前置拦截：请求在调用模型之前做规则检查——命中涉密标记或身份证号 / 手机号 / 银行卡号即返回 blocked，不产生任何 token 消耗，并写入审计。
  2. 私有化部署：模型可切换为客户自有 API Key 或本地开源模型，推理数据不出客户内网；本服务不向第三方回传输入内容。
  3. 输出不复述敏感信息：涉密审查模板只按"第 N 句 / 第 N 段"定位问题，输出校验禁止包含完整证件号与手机号（作为 hard 规则参与 pass/fail）。
  4. 最小权限：模板按岗位分配，越权请求返回 403（与版本分层授权同源），不做"全开放"。
  5. 全量审计：每次运行记录 时间 / 模板 / 结论 / token 与成本 / 客户端，留存 180 天，可导出核查。

三、验收标准（可现场复现）

能力判据
模板可用6 个模板各一键起任务，返回 verdict + checks[] 明细
自动判断hard 任一不过 → fail；仅 soft 不过 → needs_human；全过 → pass
涉密拦截输入含"机密"或身份证号 → blocked，tokens=0，审计有 precheck_blocked
审计可查GET /api/gov/runs 返回真实记录；GET /api/gov/runs/<id> 可回看逐条 checks
边界如实说明：本服务不自建涉密网（依赖客户既有保密网络与管理制度）；"前置拦截"是关键词与正则级别的技术兜底，不能替代人工保密审查； 若需国密算法 / 等保测评材料 / 三方渗透报告，属另行交付项（可提供设计与整改清单，不做无依据承诺）。
