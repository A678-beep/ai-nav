先说明白：记忆只留在你的手机里

为了第二次打开就能自动填好起点、城市和常去地点，我们想把下面这些信息存进浏览器的 IndexedDB。它们不会上传到服务器，也不会有账号同步。

会存在本机：家 / 公司 / 城市 / 车牌尾号 / 常用出行方式 / 缓冲时间 / 常去地点别名 / 各类型默认停留时长 / 最近 20 次规划历史。
不会上传：历史记录、完整记忆库。只有当你点“AI 解析”时，本次文字与规划所需的偏好字段会发给服务器用于当次解析，结果返回后不在服务器保存。
  • 你可以随时在“记忆”里逐条修改/删除，或一键清空全部。
  • AI 结果仅供规划参考，请自行核实营业时间、门牌与限行。
