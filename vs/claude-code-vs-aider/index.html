Claude Code vs Aider：怎么选

要 agent 自主读仓库、改多个文件并开 PR，选 Claude Code；要轻量 CLI、精确控制每次改动和 git 提交，选 Aider。

什么时候别选它

不选 Claude Code：改动范围小、需要逐次确认、预算敏感时，Claude Code 的自动化和调用成本偏高。

不选 Aider：要它自己读整个仓库、跑测试、开 PR 时，Aider 的自主性不够，仍需人盯着每一步。
