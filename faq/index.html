Midjourney 放大后还是糊怎么办？

Stable Diffusion 报 CUDA out of memory 怎么解决？

先加 --medvram 或 --lowvram，再降分辨率、开 xformers；SD upscale 分块设 512、重叠 64，能把峰值显存压下来三成。 看完整教程 →

Cursor 中文乱码怎么修？

多半是 GBK 文件按 UTF-8 打开了。先 Reopen with Encoding → GB18030 确认内容正常，再 Save with Encoding → UTF-8，顺序反了会写坏文件。 看完整教程 →
