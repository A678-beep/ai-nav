每条素材，都有一张可验证的授权身份证

不是普通许可清单，而是「素材 → 项目 → 成片 → 客户交付」的全链路可验证护照：SHA-256 内容指纹 + 台账哈希链 + Ed25519 签名，客户可一键导出给甲方/平台审核，任一方都能独立验真。护照证明授权信息“可查、可证、可追溯”，不构成法律意见。

① 素材级来源 / 许可 / 署名 / 地域 / 期限 / AI 标记
② 工程级剪辑继承 / 变速混剪 / 署名合并规则
③ 成片级成片指纹 + 字体/音乐/音效 + 平台合规
④ 验真级哈希链 + 数字签名 + 校验码/报告
