🧾manifest 校验清单

  • id 全局唯一：作者.功能，字母开头，仅 A-Za-z0-9._-
  • name / version / author / description 必填，version 为 x.y.z
  • type：effect / transition / subtitle / audio / workflow / panel / assetpack
  • entry：脚本为 .py，panel 为 .html，assetpack 为目录或资源文件
  • params：JSON Schema，run 前校验输入
  • permissions：仅 config.read / data.read / data.write 生效；网络/文件/子进程等直接拒绝
  • api_version：必须为 1 或 1.x；license、price 必填
安全说明：插件脚本在服务端沙箱内执行（10s 超时、512MB 虚拟地址空间、无网络、无文件系统、非 root）。平台会做静态安全审查，但这不等于对第三方插件功能与效果的背书，请自行评估后再用于生产。
